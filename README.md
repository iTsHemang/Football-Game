# Football Game

A local multiplayer football game built in Unreal Engine 5 using C++.

## Features

- Top-down player movement
- Physics-based ball
- Passing
- Through passes
- Lob passes
- Shooting
- Player switching
- Local multiplayer
- Goal detection
- Match restart / game flow

## My Role

I developed the gameplay systems and core gameplay programming in C++ and Unreal Engine.

## Technical Highlights

### Player System
Implemented the player controller and character gameplay systems, including top-down movement, input handling, player actions, and player switching.

### Ball System
Built a physics-based ball system in C++, including ball interaction, kicking, passing, shooting, and ball spawning.

### Passing & Shooting
Implemented multiple ball interaction mechanics such as standard passes, through passes, lob passes, and shooting, using physics-based impulses and gameplay logic.

### Player Switching
Implemented player switching logic for controlling different players during gameplay, including switching between players with and without possession of the ball.

### Match / Game Flow
Implemented the main gameplay flow, including player and ball spawning, goals, match state, and restarting gameplay after a goal.

### Local Multiplayer
Implemented a 2-player local multiplayer system with independent player controllers and input handling, allowing both players to control their own footballer simultaneously.
